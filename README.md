# Generator Service

Generator Service เป็นส่วนหนึ่งของระบบ AUN-QA สำหรับช่วยจัดทำรายงานการประเมินตนเอง (SAR) โดยนำข้อมูลและหลักฐานของหลักสูตรมาประกอบเป็นร่างเอกสาร Word ตาม Template ผู้ใช้สามารถตรวจสอบ แก้ไข ดาวน์โหลด และดูแหล่งอ้างอิงของเอกสารได้

## การทำงานโดยรวม

1. ผู้ใช้สั่งสร้างรายงานผ่าน Portal จากนั้น Generator ขอผลตรวจความพร้อมจาก Monitor Service เมื่อ Monitor ยืนยันว่าพร้อมจึงเริ่มสร้าง
2. Master Agent ประสานงานโหลด Template และวิเคราะห์ตำแหน่งที่ต้องเติมข้อมูล
3. Criterion Agent ระบุข้อมูลที่ต้องการ แล้ว Retrieval Manager ค้นข้อมูลและหลักฐานจากแหล่งที่เกี่ยวข้องผ่าน MCP
4. ระบบนำข้อมูลที่ค้นได้มาสร้างเนื้อหาพร้อมข้อมูลอ้างอิง และส่งผลในรูปแบบ JSON เพื่อเตรียมตรวจสอบ
5. Verification ตรวจเนื้อหาและการอ้างอิงเทียบกับหลักฐาน ก่อนเติมส่วนที่ผ่านลงใน Template และสร้างไฟล์ DOCX
6. ผู้ใช้สามารถดูตัวอย่าง แก้ไขและบันทึกฉบับร่าง ดาวน์โหลด รวมถึงดูประวัติและแหล่งอ้างอิงของเอกสาร

```text
ผู้ใช้ → Monitor ตรวจความพร้อม → โหลด Template → ค้นหลักฐาน
     → สร้างผลลัพธ์ JSON → ตรวจสอบ → จัดทำ DOCX → ตรวจแก้และดาวน์โหลด
```

JSON เป็นรูปแบบสำหรับส่งข้อมูลระหว่างขั้นตอน เช่น เนื้อหา ตาราง และข้อมูลอ้างอิง ส่วนไฟล์รายงานที่ผู้ใช้ดาวน์โหลดเป็น DOCX

หลังสร้างเอกสาร ผู้ใช้สามารถตรวจดูและบันทึกฉบับร่างได้ การดาวน์โหลดจะเก็บเอกสารเป็นเวอร์ชันสำหรับดูย้อนหลัง หน้า Reference แสดงแหล่งข้อมูลที่เชื่อมกับเนื้อหาและระบุส่วนที่ผู้ใช้แก้ไข

## โฟลเดอร์หลัก

- `backend/` — ประมวลผล สร้าง ตรวจสอบ และจัดการเอกสาร
  - `api/` — จัดการคำขอสำหรับเอกสาร ฉบับร่าง และประวัติ
  - `common/` — การตั้งค่าและส่วนทำงานร่วมกัน เช่น การเชื่อมต่อและการตรวจสอบ
  - `master_agent/` — ประสานขั้นตอนสร้างรายงานและจัดการ Template
  - `criterion_agents/` — สร้างเนื้อหาตามเกณฑ์แต่ละส่วน
  - `retrieval/` และ `mcp_server/` — ค้นและรับข้อมูลจากแหล่งข้อมูลผ่าน MCP
  - `monitor/` — ขอผลตรวจความพร้อมจาก Monitor Service
  - `document/` และ `reference/` — จัดการการแสดงผลเอกสาร การแก้ไข และแหล่งอ้างอิง
  - `scripts/` และ `test_fixtures/` — สคริปต์ทดสอบและข้อมูลสำหรับทดสอบ
  - `output/` — พื้นที่เก็บไฟล์รายงานที่สร้างขึ้น
- `frontend/` — หน้าเว็บสำหรับสร้าง ตรวจแก้ และดูเอกสาร โดย `src/` เก็บโค้ดหน้าจอและ `public/` เก็บไฟล์สำหรับหน้าเว็บ

ปัจจุบันระบบมุ่งเน้นส่วน Programme Specification (PS) ส่วน P1–P4 และ P8 ยังอยู่ระหว่างพัฒนา
